# AWS Toolkit - For Cloud Support L1 / L2

Python scripts to fix common AWS Support issues - EC2, S3, IAM.

This repo is made for learning how Cloud Support Engineers solve daily tickets.

## Files
1. `ec2_check.py` - Check EC2 instance status
2. `s3_check.py` - Check S3 bucket exists or not
3. `iam_check.py` - List IAM users

## How to Run
pip install boto3
python ec2_check.py
python s3_check.py
python iam_check.py

## What I Learned
- How to use boto3 to connect to AWS
- How Support Engineers check EC2 stopped / running issues
- How to check S3 bucket permission issues
- How to audit IAM users
